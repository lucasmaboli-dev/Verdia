# Matriz de Riscos — Verdia Ecosystem

## Riscos Técnicos

| Risco | Severidade | Probabilidade | Mitigação |
|-------|-----------|---------------|-----------|
| Fraude no oráculo físico | Alta | Média | PoPA com validação redundante + IA Computer Vision + penalidade reputacional exponencial |
| Bugs em smart contracts | Crítica | Baixa | Auditoria independente anual + testes formais de invariantes |
| Falha de hardware IoT | Média | Média | Modo offline-first + SLA < 24h + HaaS com suporte remoto |
| Viés nos modelos de IA | Média | Média | Calibração contínua + supervisão humana + publicação de critérios |

## Riscos Regulatórios

| Risco | Severidade | Probabilidade | Mitigação |
|-------|-----------|---------------|-----------|
| Token classificado como security (CVM) | Crítica | Baixa | Design soulbound + circuito fechado + sem promessa de valorização |
| Violação LGPD | Alta | Baixa | Anonimização na camada IA antes de blockchain + privacy by design |
| Mudança na PNRS | Média | Baixa | Pressão global (CSRD, Scope 3, CBAM) mantém demanda independente do município |
| Regulação restritiva de criptoativos | Média | Média | Utility token não-financeiro + consórcios governamentais |

## Riscos Econômicos

| Risco | Severidade | Probabilidade | Mitigação |
|-------|-----------|---------------|-----------|
| Token inflation (espiral da morte) | Crítica | Média | CCS ≥ 1+δ + emissão elástica + burn programado + histerese |
| Recessão macro (corte orçamento ESG) | Alta | Média | Vincular serviço a compliance compulsório (não voluntário) |
| Churn B2B | Alta | Baixa | Lock-in via APIs + switching cost institucional + NRR > 120% |
| Dependência de incentivo | Média | Média | Motivadores intrínsecos (identidade social) + Score ESG pessoal |

## Riscos de Adoção

| Risco | Severidade | Probabilidade | Mitigação |

| Fricção UX para catadores | Alta | Alta | Abstração total da complexidade cripto + UX tipo WhatsApp |

| Baixa penetração B2C | Média | Média | Gamificação hiperlocal + PLG via Esquadrões de Condomínio |
| Resistência política municipal | Média | Média | By-pass via compensação privada (B2B direto) |

## Respostas para Banca / VC

**"Por que não crédito de carbono?"** → Resíduo é passivo regulatório primário (PNRS). Carbono é derivado. Mercado de carbono em crise de credibilidade.

**"Blockchain é necessário?"** → Não é sobre descentralização. É sobre redução de custo de confiança. Impede double-spending sem auditoria manual.

**"E se o governo mudar a lei?"** → Matrizes europeias exigem rastreabilidade (CSRD, Scope 3). Governo passa a depender dos dados da Verdia.

**"Qual o moat real?"** → Qualquer um copia o app. Ninguém fork o ecossistema físico-digital calibrado. Data + Switching Cost + Comportamento.
